# Landing reference

The user supplied `portfolio-x-main (1).zip` as a visual reference. Its
Instrument Serif / Inter typography and layered gradient structure informed
the monochrome ImageShield landing page. The template's personal writing,
name, biography, social links, analytics and scripts were not reused.

Reference code: MIT, copyright2026 Shreeviraj Matale. The original license is
retained at `frontend/research-demo/fonts/portfolio-reference-LICENSE.txt`.
Local Inter and Instrument Serif font files were supplied in the archive;
their upstream SIL Open Font Licenses are retained next to them as
`inter-OFL.txt` and `instrumentserif-OFL.txt`.

The archive was path/size/symlink checked before extracting into the ignored
local cache. Neither its build script nor JavaScript was executed. No remote
font service or visitor counter is used by this workspace.
